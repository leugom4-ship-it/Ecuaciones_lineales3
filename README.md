# Ecuaciones_lineales3
## 📋 Descripción
Este proyecto implementa y compara dos métodos de integración numérica:
- *Método del Trapecio Compuesto* — aproxima con segmentos rectilíneos
- *Método de Simpson Compuesto* — aproxima con segmentos parabólicos

Ambos métodos duplican automáticamente el número de subintervalos hasta alcanzar una tolerancia especificada por el usuario.

## 📌 Requisitos
- Java JDK 8 o superior
- No requiere librerías externas

## ⌨️ Cómo compilar y ejecutar

### Desde terminal:
```bash
# Compilar todos los archivos
javac dif_e_Integracion/*.java

# Ejecutar el programa principal
